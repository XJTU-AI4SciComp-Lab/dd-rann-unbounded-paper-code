# Figures

Figures are generated by scripts in `experiments/`. Existing PNG files are retained paper and sampling outputs; the scripts can regenerate the corresponding plots from the configured CSV tables and detail files.

Main figure entry points are:

```bash
python -m experiments.example61.reproduce_figure_seed_errors61
python -m experiments.example62.reproduce_fig
python -m experiments.example63.reproduce_fig
python -m experiments.example64.reproduce_fig
python -m experiments.example65.reproduce_fig
```

Run the required table script first when a figure reads a generated result file. Do not treat sampling plots or error plots as independent numerical results; their parameters are defined by the matching configuration section.
